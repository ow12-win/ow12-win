OSCAR WINTER — DYSTOPIAN GREEN / SOFT GLOW PROFILE

1. Open your ow12-win/ow12-win profile repository on GitHub.
2. Replace its README.md with the README.md in this folder.
3. Upload the whole assets folder into the root of the repository.
4. Commit the README and assets together. Keep every filename unchanged.

Your root should contain README.md and an assets folder side by side.
You can remove the previous oscar-banner.svg and night-workspace.svg if they
are no longer used elsewhere. The new README references the new files only. Upload every file in this
assets folder; both large PNG illustrations are part of the design.

The illustrations and designed panels are local assets. The contribution
card loads live data from GitHub Readme Streak Stats and depends on that
service. All profile facts come from the information you supplied.

To change your details: edit scripts/source-about-oscar.svg and regenerate
the about assets, or use a still SVG version as described below.
Add a verified LinkedIn or email link beside the GitHub button if desired.

Original artwork generated specifically for this profile.

REBUILDING THE ANIMATIONS (optional)
Use Node.js with sharp and Python with Pillow installed.
Run node scripts/render-glow.cjs, then python3 scripts/encode-glow.py.
The render step creates temporary .glow-frames; these are not for uploading.
The SVG source for the about text is scripts/source-about-oscar.svg.

TOOLKIT ICON AND HOVER UPGRADE
Read INTERACTIVE-TOOLKIT.txt. The self-contained HTML page is the real hover
version. The GitHub README uses the animated-icon version of the same design.
To regenerate the new icons, run node scripts/build-interactive.cjs before
rendering and encoding the glow assets.
